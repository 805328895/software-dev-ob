## 2. 通用约定

> 本需求遵循项目级约定（详见仓库 CLAUDE.md 与接口文档模板），此处只标注与本项目一致的内容，不重复定义。

### 2.1 全局错误码

| code | 说明 |
|------|------|
| 200 | 成功 |
| 999 | 系统错误（SYSTEM_ERROR） |
| -10 | 参数校验错误（PARAM_ERROR） |
| 1000 | Token 校验失败 |
| 1001 | 参数错误 |

### 2.2 统一响应格式

```json
{ "code": 200, "message": "success", "data": {}, "timespan": "..." }
```

### 2.3 分页规范

继承 `HsPage<T>`：`pageNo`（从 1）/`pageSize`/`total`/`data`，分页请求 VO 继承 `HsPageSearch`。

### 2.4 时间格式

`yyyy-MM-dd HH:mm:ss`，时区 `Asia/Shanghai`，字段类型统一 `LocalDateTime` + `@JSONField(format = "yyyy-MM-dd HH:mm:ss")`。

### 2.5 字段变更标记

| 变更类型 | 标记方式 | 示例 |
|----------|----------|------|
| 新增字段 | 字段名后加 `★`，说明尾注 `【新增】` | `displayType ★` / 展示类型【新增】 |
| 删除字段 | `~~fieldName~~` + `【删除】` | `~~oldField~~` / 已废弃【删除】 |
