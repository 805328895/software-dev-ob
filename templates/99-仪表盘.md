# 项目仪表盘

> Dataview 自动统计，改需求 frontmatter 后刷新即可同步。

## 需求总览

```dataview
TABLE WITHOUT ID
  status AS "状态",
  length(rows) AS "数量"
FROM "{{kbDir}}/00-需求" AND -"{{kbDir}}/00-需求/_templates"
WHERE type = "requirement"
GROUP BY status
SORT status ASC
```

## 各模块需求数

```dataview
TABLE WITHOUT ID

```

## 各领域需求数

## 全部需求（最近更新）

```dataview
TABLE reqId AS "编号", title AS "标题", status AS "状态", module AS "模块", priority AS "优先级", updated AS "更新日期"
FROM "{{kbDir}}/00-需求" AND -"{{kbDir}}/00-需求/_templates"
WHERE type = "requirement"
SORT updated DESC
```

## 最近完成

```dataview
TABLE reqId AS "编号", title AS "标题", module AS "模块", deployed AS "部署日期"
FROM "{{kbDir}}/00-需求" AND -"{{kbDir}}/00-需求/_templates"
WHERE type = "requirement" AND status = "已完成"
SORT deployed DESC
LIMIT 10
```
