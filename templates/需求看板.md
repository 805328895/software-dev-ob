# 需求看板

> 数据源：`00-需求/` 下所有 `type: requirement` 的笔记，按 `status` 自动分组。
> 状态流转只需改需求笔记 frontmatter 的 `status` 字段，本看板自动同步。

## 需求创建

```dataview
TABLE reqId AS "编号", title AS "标题", module AS "模块", priority AS "优先级", owner AS "负责人"
FROM "{{kbDir}}/00-需求" AND -"{{kbDir}}/00-需求/_templates"
WHERE type = "requirement" AND status = "需求创建"
SORT priority ASC, created DESC
```
